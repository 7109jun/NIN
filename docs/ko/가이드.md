# NIN Shell 사용 안내서

`nin.exe`는 독립 실행형 Windows x64 셸이며, 스크립트(`.nin`)는 JSON
형식을 사용합니다. (주석과 후행 쉼표를 허용합니다.)

언어 및 CLI의 공식 규격은 `SPEC.md`를 참조하세요.

## 빠른 시작

``` text
nin REPL
nin run examples\hello.nin
nin check FILE.nin
nin validate nin build FILE.nin -o app.exe
nin workflow run examples\build.nin --report out.json
```

`nin assoc install`을 실행한 뒤 `.nin` 파일을 더블 클릭하면 해당
스크립트가 있는 폴더를 작업 폴더로 사용하여 실행됩니다. 실행 후에도 콘솔
창은 닫히지 않습니다.

## 스크립트 구조

``` json
{"nin":"1","imports":[..],"vars":{..},"const":{..},"enums":{..},"interfaces":{..},"classes":{..},"functions":{..},"main":[..],"workflow":{..}}
```

`${expr}`를 포함하는 문자열은 템플릿으로 처리됩니다.

사용할 수 있는 문장은 다음과 같습니다.

`let`, `const`, `set`, `print`, `if`, `while`, `for`, `match`, `break`,
`continue`, `return`, `throw`, `try`, `run`, `parallel`, `spawn`,
`await`, `assert`, `exit`

## 워크플로

작업(Job)은 `needs`를 사용하여 DAG(방향성 비순환 그래프)를 구성합니다.

서로 의존하지 않는 작업과 매트릭스 항목은 병렬로 실행됩니다.
`--max-parallel` 옵션으로 최대 병렬 실행 수를 지정할 수 있습니다.

작업과 단계(Step)는 다음 기능을 지원합니다.

-   `if`: 조건부 실행
-   `timeout`: 실행 시간 제한
-   `retries`: 실패 시 재시도 횟수
-   `continue_on_error`: 오류가 발생해도 계속 실행
-   `limits`: 실행 제한
-   `finally`: 작업 종료 시 실행할 처리
-   `on_error`: 오류 발생 시 실행할 처리

`Ctrl+C`를 누르면 실행 중인 모든 작업이 취소됩니다.

## 패키지 / 플러그인 / 스케줄러

### 패키지

다음 명령어로 패키지를 관리할 수 있습니다. 패키지 파일의 확장자는
`.nnpkg`입니다.

``` text
nin pkg install
nin pkg remove
nin pkg update
nin pkg search
nin pkg list
nin pkg info
nin pkg pack
nin pkg publish
```

### 플러그인

``` text
nin plugin info
nin plugin call
nin plugin list
```

플러그인은 DLL ABI를 사용합니다. 자세한 내용은 `nin-plugin` 문서를
참조하세요.

### 스케줄러

다음 명령어로 예약 작업을 관리할 수 있습니다.

``` text
nin schedule add NAME "every 5m" SCRIPT.nin
nin schedule daemon
nin schedule register
```

`register`는 Windows 작업 스케줄러에 작업을 등록합니다.

지원하는 실행 트리거는 다음과 같습니다.

-   `every`: 지정된 간격마다 실행
-   `daily`: 매일 실행
-   `weekly`: 매주 실행
-   `monthly`: 매월 실행
-   `at`: 지정된 시각에 실행
-   `logon`: 사용자 로그인 시 실행
-   `boot`: 시스템 부팅 시 실행

## 설정

설정 파일의 위치는 다음과 같습니다.

``` text
%APPDATA%\nin\config.toml
```

설정 파일은 다음 섹션을 지원합니다.

  섹션           설정 항목         설명
  -------------- ----------------- ------------------------
  `[shell]`      `prompt`          셸 프롬프트 설정
  `[shell]`      `history_size`    명령어 기록 저장 개수
  `[shell]`      `color`           셸 색상 설정
  `[run]`        `pause_on_exit`   실행 종료 시 대기 여부
  `[paths]`      `packages`        패키지 경로
  `[paths]`      `plugins`         플러그인 경로
  `[registry]`   `sources`         패키지 레지스트리 소스
  `[workflow]`   `max_parallel`    최대 병렬 실행 수

## 종료 코드

     코드 의미
  ------- ------------------
      `0` 정상 종료
      `1` 실행 실패
      `2` 명령어 사용 오류
      `3` 잘못된 스크립트
    `130` 실행 취소
